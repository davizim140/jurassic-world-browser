# Jurassic World Browser — Park Builder

Jogo de gerenciamento de parque de dinossauros para navegador, com câmera isométrica e dois modos: Campanha e Sandbox.

## Executar
Abra `index.html` em um navegador moderno. O projeto não exige instalação, servidor, dependências ou chave de API.

## Controles
- Clique em uma ferramenta e depois no terreno para construir.
- Arraste o mapa para mover a câmera.
- Use a roda do mouse ou os botões de zoom.
- Clique em uma construção para inspecioná-la.
- Salve e carregue o parque pelo painel lateral.

## Modos
- **Campanha:** orçamento inicial, custos e objetivo inicial.
- **Sandbox:** orçamento ilimitado.

## Estado atual
Primeira versão jogável em desenvolvimento. A simulação inicial inclui terreno, construções, incubação, visitantes, economia simples e salvamento local. Sistemas mais profundos (IA de dinossauros, bem-estar, genética, funcionários, missões completas e eventos) ainda serão desenvolvidos.

## Tecnologia
HTML, CSS e JavaScript nativos com Canvas 2D. Sem bibliotecas externas.
